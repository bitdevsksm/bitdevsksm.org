# Where to Find Topics

Socratic Seminars work best when attendees bring topics they find interesting.
Here are some good places to look for things worth discussing. When you find
something, share it in our [Discord](https://discord.gg/FXeMKgtYQB) so it can be
added to the next agenda.

### Newsletters & Summaries
- [Bitcoin Optech Newsletter](https://bitcoinops.org/en/newsletters/) - weekly summary of technical Bitcoin developments
- [Bitcoin Optech Topics](https://bitcoinops.org/en/topics/) - index of technical concepts with background reading

### Development Discussion
- [Delving Bitcoin](https://delvingbitcoin.org/) - forum for Bitcoin protocol development
- [Bitcoin Development Mailing List](https://groups.google.com/g/bitcoindev) - proposals and debate on protocol changes
- [Bitcoin Improvement Proposals (BIPs)](https://github.com/bitcoin/bips) - new and in-progress BIPs

### Code
- [Bitcoin Core Pull Requests](https://github.com/bitcoin/bitcoin/pulls) - changes being reviewed and merged
- [Bitcoin Core PR Review Club](https://bitcoincore.reviews/) - weekly walkthroughs of Bitcoin Core PRs
- [Lightning Network Specifications (BOLTs)](https://github.com/lightning/bolts)
- Lightning implementations: [LND](https://github.com/lightningnetwork/lnd), [Core Lightning](https://github.com/ElementsProject/lightning), [Eclair](https://github.com/ACINQ/eclair), [LDK](https://github.com/lightningdevkit/rust-lightning)

#### Golang Projects
Go is our primary language at BitDevsKSM, though contributions and discussions
in Rust, C++, C, Zig and other languages are just as welcome. These Go projects
are a great place to find topics, and pull requests and issues to review or
contribute to:
- [btcd](https://github.com/btcsuite/btcd) - full node implementation in Go, including the `btcutil`, `btcec` and `txscript` packages
- [btcwallet](https://github.com/btcsuite/btcwallet) - wallet daemon built on btcd
- [Neutrino](https://github.com/lightninglabs/neutrino) - privacy-preserving light client using compact block filters (BIP 157/158)
- [LND](https://github.com/lightningnetwork/lnd) - Lightning Network Daemon
- [Taproot Assets](https://github.com/lightninglabs/taproot-assets) - issuing assets on Bitcoin and Lightning
- [Loop](https://github.com/lightninglabs/loop) - submarine swaps for Lightning liquidity
- [Lightning Terminal](https://github.com/lightninglabs/lightning-terminal) - node management UI bundling LND, Loop and Taproot Assets
- [chantools](https://github.com/lightninglabs/chantools) - recovery tools for LND channels and funds
- [Ark](https://github.com/ark-network/ark) - Ark protocol implementation in Go
- [Good first issues](https://github.com/search?q=org%3Abtcsuite+org%3Alightningnetwork+org%3Alightninglabs+label%3A%22good+first+issue%22+state%3Aopen&type=issues) across btcsuite, LND and Lightning Labs repos

### Q&A and Community
- [Bitcoin Stack Exchange](https://bitcoin.stackexchange.com/) - technical questions and answers
- [Stacker News](https://stacker.news/) - Bitcoin news and discussion

### Learning
- [Mastering Bitcoin](https://github.com/bitcoinbook/bitcoinbook) and [Mastering the Lightning Network](https://github.com/lnbook/lnbook)
- [Btrust Pathways](https://pathways.btrust.tech/) - structured study materials for Bitcoin developers
- Past BitDevs agendas from other cities, e.g. [NYC BitDevs](https://www.nybitdevs.com/)

### Security & Incidents

- [CVE list on the Bitcoin Wiki](https://en.bitcoin.it/wiki/Common_Vulnerabilities_and_Exposures)
